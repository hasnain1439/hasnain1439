### 🔭 Currently Building — Storestack

![Status](https://img.shields.io/badge/status-in%20development-orange?style=flat-square)

A **multi-tenant, multi-store headless commerce SaaS** — think BigCommerce, but organized tenant-wise, so each business can run multiple stores (electronics, solar, general e-commerce) with a storefront built in any frontend tech.

- 🏢 **Multi-tenancy** with role-based access: Super Admin → Company Admin → Employee, plus self-signup Customers
- 🔐 **JWT auth** (HTTP-only cookies + Bearer tokens), bcrypt hashing, email verification via Nodemailer
- 🗂️ Modular REST API (Auth, Categories, and more) documented with **Swagger**
- 🔌 **Headless architecture** — any React / Next.js storefront can plug into the API

**Tech:** Node.js · Express · PostgreSQL · Prisma ORM · JWT · Swagger

### 🎓 Featured Project — Smart Learning Management System (FYP)

A full-stack LMS with separate **Admin/Teacher** and **Student** portals, built as my final year project.

- 🔐 **Secure authentication** — JWT with HTTP-only cookies, bcrypt, email verification, forgot/reset password
- 🧑‍🏫 **Face-verified attendance** — webcam capture to verify users before marking attendance
- 🎥 **Live classes** — class schedules with **Google Meet** links generated via Google APIs
- 📚 **Course & enrollment management** — courses, enrollments, auto-generated roll numbers
- 📝 **Quiz engine** — create quizzes, students attempt them and view results
- 📊 **Analytics dashboards** — enrollment charts, active students, deadlines and live schedules
- 🛡️ Validation with **Zod**, hardened with **Helmet** and CORS

**Tech:** React 19 · Vite · Tailwind CSS · Recharts · Node.js · Express · TypeScript · **PostgreSQL** · Drizzle ORM · Docker

🔗 [Live Demo](https://fyp-lms-omega.vercel.app) · [Frontend Code](https://github.com/hasnain1439/FYP-LMS) · [Backend Code](https://github.com/hasnain1439/backend-fyp)
